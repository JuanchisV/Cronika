# **App Name**: CRØNIKA

## Core Features:

- Data Input: Allow users to manually input their academic data including name, major, semester, subjects, professors, and availability.
- Manual Schedule Creation: Enable users to manually create their weekly class schedule by dragging and dropping classes or entering them into a form.
- AI-Powered Schedule Generation: AI powered tool for creating an entire class schedule at once, given a prompt describing all data. Can suggest smart recommendations considering existing schedule constraints.
- Schedule Visualization: Visualize the schedule in a modern, responsive, and easy-to-read graphical format.
- Schedule Export: Enable users to export their schedules in PNG or PDF format.
- Entry Page Design: Use a 3D design from Spline for the entry page.

## Style Guidelines:

- Primary color: Saturated purple (#A050BE) to convey both intelligence (via blue) and energy (via red) related to optimizing study schedules.
- Background color: Black, to provide a modern aesthetic.
- Accent color: Soft blue (#7CB9E8), which provides a calm and reliable feeling.
- Use a modern, clean, sans-serif font for headers and body text to ensure readability and convey a sense of innovation.
- Incorporate flat, line-style icons for navigation and key features, maintaining a consistent and modern aesthetic.
- Implement a responsive grid-based layout to ensure optimal viewing and usability across various devices.
